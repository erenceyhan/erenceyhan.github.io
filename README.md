# Aylik Senet Hesap

Bu proje, masaustu olarak yazilan aylik odeme planlayici uygulamasinin React tabanli web surumudur.

## Ozellikler

- Kalem bazli odeme girisi
- Aylik sabit odeme plani hesaplama
- Kalem kapaninca kalan odemenin sonraki kaleme otomatik aktarimi
- CSV indirme
- GitHub Pages uyumlu Vite yapisi

## Gelistirme

```bash
npm install
npm run dev
```

## Uretim derlemesi

```bash
npm run build
```
